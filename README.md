# Faunetra

Videojuego educativo sobre biodiversidad y restauración de refugios de Chile.

El sitio de GitHub Pages sirve `index.html` y los archivos de la exportación Web de Godot. Esta rama contiene la distribución jugable.

Versión de juego: **2026.11.11-piloto1**. Desde **Perfil → Preparar prueba** se puede iniciar una sesión desde cero con código de participante, respaldo de la partida anterior y modo aula. La sesión de prueba usa Explorador.

[Cuestionarios PRE y POST para participantes](cuestionarios.html), versión **2026.11.11-v4**. Las respuestas se descargan en el equipo del participante y se entregan al evaluador. No se envían automáticamente a un servidor.

Rompecabezas permite consultar la foto de referencia y muestra el progreso. Memorice muestra parejas e intentos y da más tiempo para observar las cartas. Ambos conservan el resultado al cambiar de pestaña.
